# 📱 Quick Reference - Save from Phone

## ⚡ The Fastest Way

### On ANY App (Substack, Twitter, Safari, etc.):

```
1. Tap SHARE button
2. Select TELEGRAM
3. Choose your bot
4. Type tags: #coding @curriculum
5. Send
6. ✅ SAVED!
```

**That's it!** 2 seconds to save anything.

---

## 🎯 Common Apps

### 📰 Substack
```
Article → Share → Telegram → Bot
Add: #writing @articles
```

### 🐦 Twitter/X
```
Tweet → Share → Copy Link
→ Telegram → Bot → Paste
Add: #twitter @threads
```

### 📺 YouTube
```
Video → Share → Telegram → Bot
Add: #tutorial @learning
```

### 🌐 Safari/Chrome
```
Page → Share → Telegram → Bot
Add: #research @papers
```

### 📱 Reddit
```
Post → Share → Telegram → Bot
Add: #reddit @interesting
```

---

## 💬 Message Format

### Simple:
```
https://article.com
```

### With tags:
```
https://article.com #coding #tutorial
```

### With folder:
```
https://article.com @curriculum
```

### With both:
```
https://article.com #ai @research
```

### Multi-word folder:
```
https://article.com @"phd research"
```

## 🤖 Bot Commands

| Command | What it does |
|---------|--------------|
| `/list` | Show recent 5 items |
| `/folders` | List all folders |
| `/tags` | List all tags |
| `/stats` | Your statistics |
| `/help` | Show help |

## 🚀 Power User Tips

### 1. Pin Your Bot
```
Telegram → Your bot → 
Long press → Pin to top
```

### 2. Create Templates
```
Save drafts in bot for reuse:
- #work @projects
- #reading @books
- #research @papers
```

### 3. Batch Save
```
Copy URLs quickly:
1. Share link 1 → Send
2. Share link 2 → Send  
3. Share link 3 → Send
```

## 🆘 Quick Troubleshooting

**Telegram not in share menu?**
→ Restart Telegram app

**Want faster access?**
→ Add Telegram widget to home
