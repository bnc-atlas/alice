# 📱 SMS Usage Examples - Real World Scenarios

This guide shows you exactly how to use SMS to save content to your Second Brain with practical, real-world examples.

## 🎯 Quick Reference

| What you type | What happens |
|---------------|--------------|
| `URL` | Saves with auto-detected metadata |
| `URL #tag` | Adds tag (creates if new) |
| `URL @folder` | Adds to folder (creates if new) |
| `URL #tag @folder` | Adds tag AND folder |
| `#multi-word-tag` | Creates hyphenated tag as "multi word tag" |
| `@"multi word"` | Creates multi-word folder |

## 📚 Common Use Cases

### 1. Saving Articles While Browsing

**Scenario**: You're scrolling Twitter and find an interesting article

```sms
https://techcrunch.com/article-about-ai #ai #news @quick-reads
```

**Result**: 
- Article saved with title and thumbnail
- Tagged: "ai", "news"
- Folder: "quick reads"
- Status: To Read

## 🎨 Tag Organization Tips

### Use Consistent Tags

**Good Practice**:
```sms
#deep-learning (always hyphenated)
#machine-learning (consistent format)
#ai (short form)
```

**Avoid**:
```sms
#deeplearning, #deep_learning, #DeepLearning (mixing formats)
```

### Create Tag Hierarchies

```sms
# Broad to specific
#programming → #python → #django
#design → #ui-design → #figma
#business → #marketing → #seo
```

Example usage:
```sms
https://article.com #python #django #tutorial @curriculum
https://design-article.com #ui-design #figma #inspiration @work
```

## 💡 Pro Tips

### 1. Create Templates for Recurring Needs

**Daily News**:
```sms
[URL] #news #daily @quick-reads
```

**Tech Articles**:
```sms
[URL] #tech #article @curriculum
```

**Inspiration**:
```sms
[URL] #inspiration #design @mood-board
```

### 2. Use Emojis in Folder Names (via web app)
While you can't type emojis via SMS, you can rename folders in the web app:
- 📔 Journal
- 📚 Curriculum  
- 💼 Work
- 🎥 Watch Later

### 3. Batch Processing
Send multiple texts in succession:

```sms
https://article1.com #coding @curriculum
https://article2.com #coding @curriculum
https://article3.com #coding @curriculum
```

All three get saved quickly with the same tags and folder.

### 4. Fix Mistakes
If you forget a tag or folder:
1. Check the web app
2. Edit the content item
3. Add missing tags/folder

## 🔍 Finding Your Saved Content

After saving via SMS, find your content in the web app by:

1. **Folder**: Click the folder in the sidebar
2. **Tag**: Click tags to filter
3. **Search**: Use the search bar for keywords
4. **Status**: Filter by "To Read", "In Progress", etc.

## 🆘 Troubleshooting

**Tag not showing up?**
- Check you used `#` not `@`
- Verify spelling in web app
- Tags with hyphens become spaces: `#deep-learning` → "deep learning"

**Folder not created?**
- Use `@` not `#`
- For multi-word, use quotes: `@"my folder"`
- Check web app sidebar for new folder

**Content saved without metadata?**
- Some sites block scraping
- Add title manually in web app
- Or use format: `Article: [Title] [URL] #tags @folder`
